# askFinz

**An AI platform built on its own index of the web.**

Most AI products rent their search from someone else. askFinz reads the web itself: pages read in full, filed into typed collections by what they are, so every answer comes with the passage it came from and its source.

## What you get with one sign-in

- **380+ AI models**, routed to the right one for each job, with no lock-in
- **Workspaces** for research, search, news, code, chat, data, finance, travel, maps, storage and more
- **Search** that answers from our own index with the passage and its source, not ten links
- **Research** projects with citations built in
- **askFinz Drive** for your files and workspaces
- **Browser extension** for Chrome, Edge, Firefox and Safari: a side panel that reads the page you are on
- **Desktop app** for Windows, macOS and Linux, with its own agent-driven browser
- **askFinz OS**, a Linux distribution that turns a machine into a managed askFinz device
- **Indexer nodes**: lend a spare PC, Raspberry Pi, Mac or Docker host to the index

The extension and desktop app start from **$8.19 a month** (about EUR 7), with no token caps.
